# TAMAS — تماس با لید

پنل کارشناس PWA (Progressive Web App) برای تماس با صاحبان سایت‌های وردپرس.

این یک اپلیکیشن آفلاین است که روی گوشی کارشناس نصب می‌شود. لیدها از یک فید JSON وارد می‌شوند و کارشناس می‌تواند بدون اینترنت با آن‌ها تماس بگیرد، وضعیت هر لید را ثبت کند، جلسه بگذارد، و از گفتار آمادهٔ تماس استفاده کند.

## ویژگی‌ها

- **آفلاین کامل** — Service Worker همهٔ فایل‌ها را کش می‌کند؛ بدون اینترنت هم کار می‌کند.
- **تقویم شمسی** — تاریخ‌های جلسه و پیگیری به صورت شمسی (جلالی) نمایش داده می‌شوند.
- **ماشین وضعیت تماس** — هر لید می‌تواند وضعیت‌های مختلفی داشته باشد: تماس اول، قرار جلسه، قرارداد، انصراف، اشتباه بودن شماره و غیره.
- **گفتار تماس** — برای هر لید یک اسکریپت خواندنی تولید می‌شود که کارشناس از روی آن به صاحب سایت می‌گوید. شامل: چه مشکلاتی دیده شده، هر مشکل برای مشتری چه معنایی دارد، چه ضرری می‌رسد، و اگر درست شود چه سودی دارد.
- **پیگیری خودکار** — لیدهایی که نیاز به پیگیری دارند با رنگ زرد یا قرمز مشخص می‌شوند.
- **جلوگیری از تماس تکراری** — شماره‌های تکراری شناسایی و علامت‌گذاری می‌شوند.
- **کپی متن تماس** — کارشناس می‌تواند متن گفتار را کپی کند و در واتساپ یا پیامک بفرستد.

## ساختار فایل‌ها

| فایل | نقش |
|------|-----|
| `index.html` | صفحهٔ اصلی — سه بخش: خانه، لیدهای امروز، لیدها |
| `app.js` | منطق اپلیکیشن: وضعیت‌ها، گفتار تماس، تقویم شمسی، مدیریت داده |
| `styles.css` | استایل‌های پنل (RTL، فارسی، رنگ‌های وضعیت) |
| `jalali.js` | تبدیل تاریخ میلادی به شمسی با دقت کامل |
| `sw.js` | Service Worker برای کش آفلاین |
| `manifest.json` | مشخصات PWA (آیکون، نام، تم رنگ) |
| `icons/` | آیکون‌های اندروید/iOS برای نصب روی صفحهٔ اصلی |
| `jalali.test.js` | تست واحد تقویم شمسی (ICU، رفت‌وبرگشت، طول ماه) |

## نحوهٔ استفاده

1. این فایل‌ها را روی یک سرور استاتیک (یا GitHub Pages) قرار بدهید.
2. از گوشی کروم باز کنید و **Add to Home Screen** بزنید.
3. فید JSON لیدها را از طریق **اشتراک‌گذاری فایل** یا **paste کردن JSON** وارد کنید.
4. روی هر لید بزنید → **تماس بگیرید** → وضعیت را ثبت کنید.
